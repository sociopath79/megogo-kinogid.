# MEGOGO • Кіногід

Мобільний україномовний телегід на основі публічного XMLTV EPG: https://iptv-epg.org/files/epg-ua.xml

## Як запустити
1. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
2. GitHub → Actions → Update EPG guide → Run workflow (перший запуск вручну).
3. Далі GitHub Actions запускається щодня о 03:20 UTC. GitHub може затримувати заплановані запуски.

Адреса Pages буде на кшталт https://sociopath79.github.io/megogo-kinogid./ (GitHub покаже точну адресу після публікації).

## Обмеження
- Це **не** офіційний перелік каналів підписки MEGOGO «Максимальна». Відбираються канали за ключовими словами у назвах. Для точного переліку потрібна звірка з підпискою.
- XMLTV не гарантує наявність усіх програм, жанрів і років. Відсутні дані позначені.
- IMDb навмисно залишено порожнім: без перевіреної відповідності IMDb ID рейтинги не підставляються. Наступний етап — безпечне зіставлення з IMDb та перевірка джерел.
- Перш ніж увімкнути Pages, запустіть workflow, щоб з'явився data/guide.json.
- Якщо EPG недоступний, Action завершується помилкою і не публікує вигадані дані.
